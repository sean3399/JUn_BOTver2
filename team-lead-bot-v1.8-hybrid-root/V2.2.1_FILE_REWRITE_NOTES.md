# JUN BOT V2.2.1 · File Rewrite Export

## 변경 목적
V2.2.0의 JUN Rewrite는 수정안을 화면에서 채택하는 데서 끝났습니다. V2.2.1은 채택된 수정안을 실제 원본 파일에 반영한 수정본을 생성하고 브라우저로 전달합니다.

## 사용자 흐름
1. 파일 검토
2. JUN Rewrite에서 문장만 / 팀장식 구조화 / 상신용 수정 생성
3. `수정안 채택`
4. `수정본 파일 생성`
5. 원본 형식 기반 수정본 다운로드

## 구현
- `components/ReviewWorkspace.js`: 수정안 채택과 파일 생성을 분리, 파일 생성 버튼/상태 추가
- `components/ChatPane.js`: 검토 시 사용한 File 객체를 현재 브라우저 세션에만 보관하고 파일 생성 시 재업로드/다운로드
- `app/api/rewrite-file/route.js`: Private Blob 원본을 읽어 수정 엔진 실행, 결과 파일 또는 다중 파일 ZIP 반환
- `lib/fileRewrite.js`: PPTX/DOCX/XLSX/PDF/TXT/MD/CSV 형식별 실제 패치 엔진
- PDF: pdf-lib Text Annotation으로 원본 페이지에 JUN Rewrite 주석 추가(별도 폰트 파일 불필요)

## 안전장치
- 채택된 `jun-rewrite`만 파일에 반영
- 새 숫자/근거를 파일 생성 단계에서 추가하지 않음
- evidence snippet을 원문 anchor로 사용
- 원문 위치를 찾지 못한 Office 문서는 임의 위치를 수정하지 않음
- PDF 위치가 확인되면 해당 페이지에 주석, 위치가 없으면 1페이지에 위치 미확인 주석으로 남김
- Blob은 수정본 생성 응답 후 즉시 삭제

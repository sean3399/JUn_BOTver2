# JUN BOT V2.1.4 Unified Blob Pipeline

- Small/large file branching removed. Every attachment uses Private Blob.
- Browser upload: OIDC Signed PUT.
- Blob key: ASCII-only UUID path; original display filename kept separately.
- Upload response pathname is used when available instead of assuming the signed pathname.
- Review read: OIDC Signed HEAD -> Signed GET with short propagation retries.
- The server processes one uploaded file at a time to reduce memory pressure on 100MB+ reports.
- Each Blob is deleted immediately after parsing/OCR, with a final cleanup pass as a safety net.
- `/api/review` now accepts JSON Blob descriptors only; FormData attachment upload is intentionally removed.
- `/api/health` reports `version: 2.1.4-beta`, `unifiedBlobUploadPipeline: true`, and `blobUploadMode: all-files-oidc-signed-put`.

# 팀장님 시뮬레이터 V1.9 · Judgment OS

실제 Teams처럼 짧게 대화하는 **팀장님 말풍선**과, 말풍선 옆 `?`에서 확인하는 **판단 대시보드**를 분리한 Adaptive Manager 버전입니다.

## V1.9 핵심 변화

- **Judgment OS 추가:** 문서 점수 6축과 별개로 팀장님의 반복적인 판단 태도 6개를 모델링
  - FACT FIRST — 팩트와 의견/추정을 분리
  - WHY TRACE — 숫자뿐 아니라 반영·삭감 판단의 이유와 검토 흔적까지 추적
  - PROPORTIONAL CONTROL — 문제 규모·사용빈도에 맞는 최소 충분 통제
  - REVISABLE OPINION — 의견은 분명히 제시하되 새 팩트가 나오면 자연스럽게 수정
  - RIGHT DECISION OWNER — 규정/담당자/당사자/상위 의사결정자 중 적절한 판단 주체 구분
  - ACT WHEN CLEAR — 명확한 일은 먼저 실행, 불명확한 일은 시안·샘플·추가 사실 확인 후 결정
- **채팅에도 `?` 대시보드:** 파일 검토뿐 아니라 업무형 일반 채팅 응답에도 판단 OS/6축 해설을 붙임
- **팩트/의견 분리 카드:** 현재 문서/대화에서 확인된 팩트 단서와 의견·추정 단서를 별도로 표시
- **설명가능성/방어가능성 강화:** 예산·증원·삭감 결과보다 “나중에 왜 그렇게 했는지 설명 가능한가”를 별도 근거로 점검
- **판단 주체 진단:** 회사가 정할 일인지, 당사자 선택을 받을지, 의사결정권자에게 옵션을 올릴지 구분
- **선조치 판단:** 계획서만 남기는 안보다 지금 바로 완료 가능한 후속조치가 있는지 확인
- **과잉 단정 가드:** 확인 중·미결정·시안 검토 단계에서 `무조건`, `정답`, `확실히` 같은 단정형 답변을 차단
- **기존 V1.8.4 유지:** Assumption Traceability, 6축 점수, 유사 사례 참고, No Policy Invention, Teams형 짧은 응답

## 6가지 문서 판단축

사실성 / 인과성 / 정당성 / 비례성 / 실행성 / 전달성

`?` 대시보드에서 각 점수의 근거, 긍정 신호, 부족한 부분, 문서 문맥을 확인할 수 있습니다. 0~100은 통계적 확률이 아니라 실제 반응에서 추출한 **규칙 기반 패턴 점수**입니다.

## 대시보드에서 보이는 내용

1. 현재 판단 단계
2. **팀장님 판단 OS 6개**와 현재 사안에서 활성화된 원칙
3. 팩트 vs 의견/추정 분리
4. 6가지 판단축
5. 현재 문서의 필요성·금액·가정값·규정·전결·기존 공지·판단이력·판단주체 근거
6. 핵심 가정값 추적
7. 반복적으로 관찰된 판단 습관
8. 유사 실제 사례(정답지가 아니라 참고 근거)
9. 예상 후속질문
10. 판단에 반영하는 우선순위

## 이번 버전에 반영한 최신 회의 패턴

- 예산은 총액보다 항목별 산식·버퍼·필수비용과 반영/삭감 기준이 남아 있어야 함
- 증원 요청은 왜 반영했고 왜 미반영했는지 객관적인 기준과 검토 흔적을 남겨야 함
- 시스템 권한은 실제 사용빈도에 따라 상시/기간성 통제를 다르게 볼 수 있음
- 경영진단 후속조치는 계획서 제출보다 바로 끝낼 수 있는 항목을 먼저 조치 완료하는 경향
- 이미 안내된 약속은 쉽게 뒤집지 않음
- 회사가 정답을 강제로 정할 필요가 없는 사안은 당사자 선택 가능성을 검토
- 샘플·시안으로 확인해야 하는 사안은 성급히 결론 내리지 않음

## 보안/데이터 주의

- API Key는 서버 환경변수에서만 사용합니다.
- 앱 자체 DB는 없고 첨부 원문 파일을 별도 DB에 저장하지 않습니다.
- 문서에서 추출된 텍스트는 검토를 위해 OpenAI API로 전송됩니다.
- 브라우저 대화 기록은 `localStorage`에 남습니다.
- 회사 내부 민감정보 사용은 회사 정책과 보안 검토 범위 안에서 진행하세요.
- PPT/PDF/DOCX는 현재 텍스트 추출 기반이므로 시각적 배치·색상·도형 관계는 분석하지 않습니다.

## 주요 파일

- `lib/persona.js` — 팀장 판단 OS + Teams 말투
- `lib/managerLogic.js` — 6축 + Judgment OS + Assumption Trace + 판단이력/주체
- `lib/precedents.js` — 실제 사례를 적응형 참고근거로 제공
- `lib/responseGuard.js` — 정책/숫자 창작·봇형 출력·과잉 단정 차단
- `app/api/review/route.js` — 문서 분석 → 적응형 판단 → LLM 응답
- `components/ChatPane.js` — Teams UI + `?` 판단 대시보드

# 팀장님 시뮬레이터 V1.8.4 Adaptive Manager · Assumption Trace

실제 Teams처럼 짧게 대화하는 **팀장님 말풍선**과, 그 반응이 왜 나왔는지를 설명하는 **`?` 판단 대시보드**를 분리한 버전입니다.

## V1.8.4 핵심 변화

- **과거 사례 잠금 제거:** 과거 사례는 정답이 아니라 현재 판단을 보정하는 증거로 사용
- **판단 우선순위:** 현재 사실관계 → 반복 행동패턴 → 유사 실제 사례 → 제한적 LLM 추론
- **Teams형 대화 강화:** 메신저 응답은 보통 1~3문장, 최초 질문 1개 중심
- **분석과 대화 분리:** 말풍선에는 팀장님 답변만 표시하고, 옆 `?` 버튼에서 분석 확인
- **6가지 판단축 유지:** 사실성 / 인과성 / 정당성 / 비례성 / 실행성 / 전달성
- **Assumption Traceability 추가:** 숫자 → 산식 → 산식의 핵심 입력값 → 왜 그 입력값인지까지 추적
- **예산 가정값 분리:** 예상 증원, 상향률, 월 버퍼, 고액 변동분을 단순 숫자가 아니라 별도 가정으로 진단
- **가정 근거의 유형화:** 인원은 인력계획/과거 순증, 변동성 버퍼는 실적 분포/백분위, 고액 변동분은 발생빈도 근거를 우선 확인
- **점수 근거 공개:** 각 축을 누르면 긍정 신호, 부족한 부분, 현재 문서에서 잡힌 문맥을 표시
- **3층 판단 근거:** 현재 문서 / 반복 행동패턴 / 유사 실제 사례
- **현재 판단 단계:** 확인 단계 / 검증 단계 / 판단 단계 / 보완 단계
- **예상 후속질문:** 실제 채팅에서는 한 번에 쏟아내지 않고 대시보드에서만 미리 확인 가능
- **No Policy Invention:** 문서·사례에 없는 숫자, 기한, 인원 상한, 새 정책·체크리스트 생성 차단
- **봇 같은 응답 가드:** `원칙/이유/리스크/타임라인`처럼 분석 리포트형 메신저 응답 자동 재작성

## 대시보드에서 보이는 내용

`?`를 누르면 오른쪽 패널에서 다음을 확인할 수 있습니다.

1. 이번 반응의 성격과 현재 판단 단계
2. 6가지 판단축의 패턴 점수
3. 각 축 점수의 이유와 현재 문서 문맥
4. 필요성·금액 산정·핵심 가정값·규정·전결·기존 공지/관행의 근거 진단
5. **핵심 가정값 추적:** 어떤 숫자가 왜 보완/누락인지, 해당 문장과 부모 근거 상태 확인
6. 반복적으로 관찰된 팀장님 판단 패턴
7. 유사한 실제 사례가 있을 경우 그 사례의 판단 패턴과 결과 요지
8. 현재 답변 뒤에 이어질 가능성이 있는 후속질문
9. 판단에 반영한 근거의 우선순위

> 0~100 숫자는 통계적 확률이 아니라 실제 반응에서 추출한 **규칙 기반 패턴 점수**입니다.

## 회귀 테스트

```bash
npm run test:regression
```

현재 테스트에는 다음 오류 유형을 포함합니다.

- 경조금 기한 경과 사례를 무조건 새로운 예외 정책으로 뒤집는 오류
- PAYCO/과표 마감에서 임의의 인원·금액·D+ 기준을 창작하는 오류
- 축구동호회 예산에서 산정근거보다 감사 체크리스트를 과잉 생성하는 오류
- Teams 답변에 `원칙/이유/리스크/타임라인` 섹션을 붙이는 봇 같은 출력
- 6축·판단 근거·예상 후속질문 대시보드 데이터 생성
- 의료비/경조금 예산 사례에서 19명·5.3백만원·20백만원 같은 핵심 가정값의 부모 근거 누락 탐지
- 전년도 예상인원/최근 19개월 95% 실적 등 부모 근거를 추가하면 가정 추적 상태가 개선되는지 검증

```env
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5
OPENAI_REASONING_EFFORT=low
APP_ACCESS_CODE=긴-임의-접근코드
```

- `OPENAI_API_KEY`: 필수
- `OPENAI_MODEL`: 선택
- `OPENAI_REASONING_EFFORT`: 선택, 기본 `low`
- `APP_ACCESS_CODE`: 배포 시 권장

## 보안/데이터 주의

- API Key는 서버 환경변수에서만 사용합니다.
- 앱 자체 DB는 없고 첨부 원문 파일을 별도 DB에 저장하지 않습니다.
- 문서에서 추출된 텍스트는 검토를 위해 OpenAI API로 전송됩니다.
- 브라우저 대화 기록은 `localStorage`에 남습니다.
- 회사 내부 민감정보 사용은 회사 정책과 보안 검토 범위 안에서 진행하세요.
- PPT/PDF/DOCX는 현재 텍스트 추출 기반이므로 시각적 배치·색상·도형 관계는 분석하지 않습니다.

## 주요 파일

- `lib/persona.js` — 팀장님 판단 성향 + Teams형 짧은 말투
- `lib/managerLogic.js` — 6축 점수 + 축별 근거 + 판단단계 + 예상질문
- `lib/precedents.js` — 과거 사례를 정답이 아닌 적응형 판단 근거로 제공
- `lib/responseGuard.js` — 근거 없는 정책/숫자 및 봇 같은 출력 차단
- `app/api/review/route.js` — 문서 분석 → 적응형 판단 → LLM 응답
- `components/ChatPane.js` — Teams 대화 UI + `?` 판단 대시보드
